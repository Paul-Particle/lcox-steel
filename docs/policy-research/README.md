# Policy research: what counts under which framework

Background reading for issue #52 (grid emission intensity and the RFNBO check),
gathered 2026-09-07 and 2026-09-08. Each file is a standalone brief with
verbatim quotes from the primary texts and every source URL.

The question behind all of them: when the model reports a levelised cost and a
carbon intensity for iron made in one place and melted in another, which of
those emissions does any actual regulation count, and where?

The last two ask a different question from the rest. The others say what the
rules count; those two ask whether anyone in the institutions has noticed that
iron made abroad on fossil electricity owes almost no CBAM, because CBAM takes
only direct emissions for iron. The general exclusion is exhaustively
documented and, since mid-2026, formally conceded by the Commission's own
contractor. The iron-specific case — that the gap is largest exactly for the
product the EU most wants to import — is, on this evidence, absent from the
institutional record.

These are research notes, not project decisions. Numbers here have not been
adopted into `config/assumptions.yaml` — where one is, the assumption carries
its own comment and source.
